# Daybook Clickable Calendar

A blank monthly navigation calendar for the Daybook Jotform App. Date clicks open the existing Jotform Task form. This public repository contains **no planner submissions, private tasks, or appointment records**. Optional selected-date prefill requires the matching form field unique name to be configured in the browser. The original Daybook application repository remains separate and private.

This component is intentionally public because GitHub Pages requires a public repository on GitHub Free. Do not add private user data to this repository.
